- First Windows build of Toolbox, ported from the macOS app.
- SSH terminals in split panes and workspace tabs, with drag-to-arrange layouts, themes and text-size shortcuts.
- RDP through the Windows Remote Desktop client, with a desktop that follows the pane size.
- File Transfer connections over SFTP, FTPS and FTP.
- Folders, credentials (vault, 1Password or ask each time), folder-level credentials, and providers that import from 1Password and Active Directory.
- Not in this build yet: VNC connections (they say so instead of opening).
- An early build: it has been exercised against test servers, not yet against production hosts. Please report anything odd.

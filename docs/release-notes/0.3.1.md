- **An installer.** `Toolbox-0.3.1-win-<arch>-setup.exe` installs Toolbox for your Windows account without asking for an administrator, adds it to the Start menu, and can be removed again under **Settings ▸ Apps ▸ Installed apps**. A copy installed this way updates itself like any other, and Installed apps goes on showing the version it has reached.
- **A disc image.** `Toolbox-0.3.1-win-<arch>.iso` opens as a disc when you double-click it. It holds the installer and the app's folder, for a PC or a virtual machine that is easier to hand a disc than a download.
- Nothing in the app itself changed, and nothing changes for the copy you have: it updated itself to this version and stays in its folder. To move to an installed copy, close Toolbox, run the installer, and delete the old folder. Your connections, credentials and settings are not in that folder and stay as they are.

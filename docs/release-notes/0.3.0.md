- Toolbox now updates itself. It looks for a new version once a day and under **Help ▸ Check for Updates…**, shows what changed, and installs it when you agree. Installing restarts the app, so it asks first when sessions are open. **Help ▸ Check for Updates Automatically** turns the daily look off. This is the last version to download by hand; keep Toolbox in a folder you can write to (not Program Files) for that to work. An update is installed only if it carries the developer's signature. A check sends the app's version and your PC's processor type, and nothing about your connections or credentials.
- Every connection now opens in a tab of its own, named after it, instead of splitting the window: SSH, remote desktop and file transfer alike. Put sessions side by side when you want to: split a pane (Alt+Shift+= or Alt+Shift+-) and open into the empty half, drop a connection from the sidebar on a pane's edge, or right-click a pane's header and choose **Move to Workspace**. A tab closes when its last session ends or is moved away. Double-click a tab to give it a name of your own; clear the name to go back to the automatic one.
- Local terminals: **File ▸ New Local Terminal** (Ctrl+Alt+T, or the new toolbar button) puts a window of your own Windows Terminal in a tab, and **New Local Terminal With** lists your Terminal profiles. Colours, fonts and keys are the ones you set in Windows Terminal. Closing an idle shell asks nothing; one that is running a program names it first. While a local terminal has the keyboard, Toolbox's own shortcuts do not work: click another pane or the sidebar first. Needs Windows Terminal (part of Windows 11).
- **Edit ▸ Find** (Ctrl+Shift+F) searches the text of an SSH terminal, including what has scrolled out of view; Enter and Shift+Enter step through the matches. **Browse Files moved to Ctrl+Alt+F** to make room.
- Fixed: with a remote desktop on screen, letters typed quickly somewhere else in the window (the sidebar's filter, for one) could go missing.
- A provider's folder now always carries the provider's name: rename the provider and its folder is renamed with everything inside, and **Location** in the provider's settings says which folder it sits in. A folder holds one provider; if your setup has two in one folder (which listed every Active Directory computer twice), the hidden one now appears next to the first, with a 2 after its name when both were called the same. Delete it from its context menu if you don't need it. Deleting a provider removes its folder as well when nothing else is in it, and a refresh that is still running when its provider is renamed, moved or deleted no longer leaves entries behind in the old place.
- Folders stay open in the sidebar when you rename or move them, and a large tree (a few thousand computers) no longer makes the filter field stall on the first letter.

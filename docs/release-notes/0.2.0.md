- The clipboard you share with remote desktops (text and files) is now offered only to the remote desktop you are working in. Before, every connected remote desktop was told about everything you copied, whichever window was in front. **View ▸ Remote Desktop ▸ Share Clipboard** turns sharing off.
- Resizing is calmer: while you drag a window edge or a divider, a remote desktop keeps its picture (shrunk to fit when its pane gets smaller) and the new size is asked for when you let go, not at every step. A remote desktop also takes the keyboard as soon as it has connected.
- **View ▸ Remote Desktop ▸ Fast Graphics**: if a remote desktop's picture comes out garbled or black on your PC, switch this off and reconnect. The picture is then decoded and drawn without the graphics card.
- Choosing a credential now has a search field: type part of a name, username or folder and everything else is hidden.
- The sidebar no longer repeats everything in "All Connections" and "All Credentials" lists; the filter field searches the whole tree.
- The window has a plain background instead of a translucent one, which fixes washed-out colours in a scaled remote desktop. Menu items that are switches (the two above, the vault's "Confirm It's You", the terminal theme) now show their check mark.
- Security: a download is refused when Windows would read its name as a device or a path (for example `COM1` or `..\x`), a remote program can no longer stall the window with an oversized terminal title, and the SSH library was updated for a timing weakness in RSA.
